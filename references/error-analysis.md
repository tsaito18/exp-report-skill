# 誤差解析と考察の組み立て

考察の質を決めるのが誤差解析。ここを「人為的ミス」「測定誤差のため」で済ませると評価が伸びない。具体的な誤差源を挙げ、可能なら桁を見積もる。

## 誤差の分類

考察ではまず誤差を2種類に切り分けると論じやすい。

- **系統誤差(systematic error)**: 一定方向に偏る誤差。原因が特定できれば補正可能。
  例: 測定器の零点ずれ・確度、電圧計の内部抵抗による負荷効果、電流計の内部抵抗、リード線・接触抵抗、温度ドリフト、校正のずれ、視差。
- **偶然誤差(random error)**: 測定ごとにばらつく誤差。複数回測定の平均・標準偏差で評価する。
  例: 読み取りのばらつき、ノイズ、電源変動。

考察では「測定値が理論値より一貫して大きい/小さい」なら系統誤差を、「ばらつく」なら偶然誤差を主に疑う、という筋道で書ける。

## 相対誤差(誤差率)

理論値・期待値があるときは必ず計算する。

$$\text{相対誤差} = \frac{|x_\text{測定} - x_\text{理論}|}{|x_\text{理論}|} \times 100\ \%$$

「ほぼ一致した」ではなく「理論値に対し 2.3% の差であった」と数値で述べる。そのうえで、その差が上で挙げた誤差源で説明できる大きさかを論じる。

## 偶然誤差の統計処理(複数回測定したとき)

- 平均値: $\bar{x} = \frac{1}{n}\sum x_i$
- 標準偏差: $s = \sqrt{\frac{1}{n-1}\sum (x_i - \bar{x})^2}$
- 平均値の標準誤差: $\sigma_{\bar{x}} = s/\sqrt{n}$
- 結果は $\bar{x} \pm \sigma_{\bar{x}}$ の形で書く。

## 誤差伝播

複数の測定量から計算で求める量 $f$ の誤差は、各量の誤差から伝播する。独立な誤差 $\Delta a, \Delta b$ に対して:

- **和・差** $f = a \pm b$: 絶対誤差が加わる。 $\Delta f = \sqrt{(\Delta a)^2 + (\Delta b)^2}$(独立な場合)。単純な上限評価なら $\Delta f = \Delta a + \Delta b$。
- **積・商** $f = a b$ や $f = a/b$: **相対誤差** が加わる。 $\frac{\Delta f}{|f|} = \sqrt{\left(\frac{\Delta a}{a}\right)^2 + \left(\frac{\Delta b}{b}\right)^2}$。
- **べき** $f = a^n$: $\frac{\Delta f}{|f|} = |n|\frac{\Delta a}{|a|}$。
- 一般式: $\Delta f = \sqrt{\sum_i \left(\frac{\partial f}{\partial x_i}\Delta x_i\right)^2}$。

どの測定量の誤差が結果に最も効くか(支配的か)を論じると考察が深くなる。

## 最小二乗法(直線当てはめ)

$y = ax + b$ を $n$ 個の測定点に当てはめる:

$$a = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - (\sum x_i)^2}, \quad b = \frac{\sum y_i - a\sum x_i}{n}$$

- 傾き $a$ と切片 $b$ の **物理的意味** を必ず述べる(例: 傾きが抵抗値、切片が接触抵抗に対応するなど)。
- 当てはまりの良さは相関係数や残差で言及できる。
- グラフには測定点と近似直線の両方を描く。

## 電気工学実験で頻出の誤差源(考察のネタ帳)

- **計器の負荷効果**: 電圧計の内部抵抗が有限 → 並列に入ると回路を乱す。電流計の内部抵抗 → 直列で電圧降下。どちらの接続(電圧計を負荷側/電源側)かで系統誤差の向きが変わる。
- **計器の確度**: アナログは「最大目盛 × 階級(%)」、ディジタルは「±(読み × % + 末位カウント)」。データシート/階級表示から見積もる。
- **接触抵抗・リード線抵抗**: 低抵抗測定で効く。四端子法で除ける、という議論につながる。
- **温度依存**: 抵抗の温度係数、半導体の特性変化。
- **オシロ/AD の量子化・帯域**: 分解能、サンプリング、プローブの影響。
- **電源・発振器の精度と安定度**。

## 考察を「言い換え」にしないためのチェック

結果の章に書いた事実をなぞるだけになっていないか。以下を1つ以上含めると考察になる:

1. 測定値と理論値を **数値で** 比較し、ずれを定量化したか。
2. ずれの原因を **具体的な誤差源** で説明し、桁の見積もりを試みたか。
3. 結果が原理で述べた **関係(比例・指数など)を支持するか** を判断したか。
4. どの誤差源が **支配的か** を論じたか。
5. 改善するなら何を変えるか(測定法・計器・条件)に触れたか。
